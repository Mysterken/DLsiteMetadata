# 快速开始指南

## 5分钟快速上手

### Windows用户

1. **双击运行** `start.bat`
2. 等待启动完成
3. 浏览器访问 `http://localhost:5000`

### Linux/Mac用户

```bash
chmod +x start.sh
./start.sh
```

或手动启动：

```bash
# 1. 创建虚拟环境
python3 -m venv venv

# 2. 激活虚拟环境
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行应用
python app.py
```

## 第一次使用

### 1. 添加第一个游戏

访问首页后，在左侧面板：

```
Work ID: RJ123456  ← 输入DLsite游戏的RJ号
↓
点击"抓取游戏"按钮
↓
等待3-5秒，游戏信息会自动显示
```

### 2. 批量添加游戏

如果你有多个游戏要添加：

1. 点击"批量抓取"按钮
2. 在弹窗中每行输入一个RJ号：
   ```
   RJ123456
   RJ234567
   RJ345678
   ```
3. 点击"开始抓取"
4. 前往"任务管理"页面查看进度

### 3. 管理你的游戏

在游戏卡片上有4个快捷按钮：

- 👁️ **查看**：查看游戏详情
- ⭐ **收藏**：加入收藏列表
- ✓ **拥有**：标记已购买
- 🚫 **屏蔽**：屏蔽不喜欢的游戏

### 4. 使用分类

1. 进入游戏详情页
2. 在"分类管理"区域
3. 选择分类并添加
4. 在"我的收藏"页面按分类浏览

## 常用功能

### 搜索游戏

在首页搜索框输入：
- 游戏名称
- RJ号码
- 社团名称

### 筛选游戏

使用左侧筛选面板：
- ☑️ 收藏的游戏
- ☑️ 已拥有的游戏
- ☑️ 已屏蔽的游戏
- 📁 按分类筛选

### 排序方式

支持多种排序：
- 添加时间（默认）
- 发售时间
- 评分高低
- 销量多少
- 标题字母

## 速率限制说明

为避免被DLsite封禁，系统默认：
- 每2秒抓取1个游戏
- 自动重试失败的请求
- 遇到429错误会自动减速

**建议**：
- ✅ 使用批量抓取，让程序后台运行
- ✅ 睡前启动批量任务，第二天查看结果
- ❌ 不要频繁手动抓取
- ❌ 不要修改配置文件中的速率设置（除非你知道后果）

## 数据备份

你的所有数据都在：
```
web-app/dlsite_games.db  ← SQLite数据库文件
```

**备份方法**：
1. 停止程序
2. 复制 `dlsite_games.db` 文件
3. 保存到安全位置

**恢复方法**：
1. 停止程序
2. 用备份文件替换 `dlsite_games.db`
3. 重新启动程序

## 故障排除

### 端口5000被占用

修改 `app.py` 最后几行：

```python
app.run(
    host='0.0.0.0',
    port=5001,  # 改成其他端口
    debug=True
)
```

### 无法访问DLsite

检查网络连接，确保可以正常访问 https://www.dlsite.com

### 某些游戏抓取失败

- 可能是限定年龄的内容需要登录
- 可能是网络波动，稍后重试
- 查看"任务管理"页面的错误信息

### 图片无法显示

- 检查网络连接
- 部分图片可能需要特定访问权限
- 可以在 `config.py` 中启用本地图片保存

## 进阶配置

编辑 `config.py` 文件：

```python
# 修改默认语言
DEFAULT_LANGUAGE = 'ja_JP'  # 日文

# 调整每页显示数量
GAMES_PER_PAGE = 30

# 修改数据库位置
SQLALCHEMY_DATABASE_URI = 'sqlite:///path/to/your/database.db'
```
